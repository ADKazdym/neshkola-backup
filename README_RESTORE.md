# Зашифрованные копии данных «Не школа»

В каталоге `data/` лежат ежедневные копии: `neshkola_data_<дата>.tar.gz.enc` (данные детей + настройки),
`bot_applications_<дата>.db.gz.enc` (база заявок бота «Жёлудь») и `server_secrets_<дата>.tar.gz.enc`
(.env бота «Жёлудь», его credentials.json и пароль nginx; расшифровываются так же).
Файлы зашифрованы AES-256 паролем, который знает только Андрей (менеджер паролей).
Без пароля прочитать их нельзя — ни здесь, ни на GitHub.

## Как восстановить

1. Скачать нужный `.enc` файл (последний по дате — самый свежий).
2. Расшифровать и распаковать (спросит пароль):

```bash
openssl enc -d -aes-256-cbc -pbkdf2 -iter 600000 -in neshkola_data_2026-10-07_2115.tar.gz.enc | tar xzf -
```

   Появятся папка `data/` (карточки детей и служебные файлы) и файл `.env` (токен бота, прокси).
3. Положить `data/` и `.env` в `/root/neshkola/` на сервере, перезапустить `neshkola-api` и `neshkola-bot`.

Код приложения лежит в другом (тоже приватном) репозитории `neshkola`.
